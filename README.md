# デスク埋込型 スマート・オーディオセレクター＆コントローラー (MyAudio)

本リポジトリは、[SPEC.md](SPEC.md) に基づいて完全設計された「デスク埋込型 スマート・オーディオセレクター＆コントローラー」のKiCad設計データ一式および製造・組立ドキュメントです。

---

## 1. プロジェクト概要

- **設計コンセプト**: 
  - 手元のデスク天板に埋め込む小型操作部（**サテライト基板**）
  - デスク天板裏に配置し、音響信号経路を最短化する主基板（**メイン基板**）
  - 両基板を市販の **LANケーブル（RJ45 Cat6）1本** で接続するスマートセパレート構成
- **手作業組立（DIY手はんだ）への最適化**:
  - すべての受動部品および主要ICに **THT（スルーホール / DIP）部品** を採用。
  - プロ用リレー・コネクタ・マイコン部も含め、一般的なはんだごて（30W〜40W程度）で失敗なく組み立て可能。
- **高音質アナログ・デジタル完全分離設計**:
  - PT2258（I2C 電子ボリュームIC）のアナロググランド（AGND）とデジタルグランド（DGND）を独立プレーン化し、1点（NetTie）のみで結合。
  - 音声信号のリレー切り替えには、高信頼性金メッキ接点シグナルリレー（OMRON G6K-2P-Y）を採用。
- **設計品質（完全検証済み）**:
  - サテライト基板: **ERC 0件、DRC 0件、未配線 0件**
  - メイン基板: **ERC 0件、DRC 0件、未配線 0件**

## 3. 基板仕様およびレイアウト

### 3.1 サテライト基板 (`pcb/satellite/`)
- **基板外形**: 60.0 mm × 45.0 mm（角丸 R=2.0mm）
- **レイヤー構成**: 2層 (FR-4, 1.6mm厚, 1oz銅箔)
- **前面操作部配置**:
  - 左側: 0.96インチ I2C OLED (SSD1306, 128×64)
  - 中央上: 出力切替用トグルスイッチ (SPDT ON-ON)
  - 中央下: インジケータLED × 2（SPK緑 / HP青、φ3mm）
  - 右側: クリック付きロータリーエンコーダ（音量調整 & プッシュでMute）
- **背面接続部**: RJ45モジュラージャック（Cat6 LANケーブル直結）
- **製造データ**: `pcb/satellite/gerber/` 配下に標準2層ガーバー・NCドリル完備（JLCPCB / PCBWay / Elecrow等にZIP圧縮してそのまま入稿可能）。

### 3.2 メイン基板 (`pcb/main_board/`)
- **基板外形**: 100.0 mm × 65.0 mm（角丸 R=3.0mm、M3取付穴×4）
- **レイヤー構成**: 2層 (FR-4, 1.6mm厚, 1oz銅箔)
- **配置・ゾーン構成**:
  - **北側（アナログ領域）**: 
    - 3.5mmステレオジャック×3（LINE IN、SPK OUT、HP OUT）
    - PT2258 電子ボリューム部（DCカット音響コンデンサ C1〜C4）
    - 高精度 B.Cu アナロググランド（AGND）ベタプレーン
  - **中央**: 
    - 信号切替用 高信頼性シグナルリレー（OMRON G6K-2P-Y）
    - 1点結合用ネットタイ（NT1）
    - LCノイズ低減電源フィルタ（L1 10uH + C6 100uF + C7 0.1uF）
  - **南側（デジタル領域）**:
    - Seeed Studio XIAO ESP32-C6 マイコンソケット
    - サテライト通信用 RJ45コネクタ
    - B.Cu デジタルグランド（DGND）ベタプレーン
- **製造データ**: `pcb/main_board/gerber/` 配下に完全な製造ガーバー・NCドリル完備。

## 4. RJ45 (Cat6 LANケーブル) ピンアサイン

サテライト基板とメイン基板間は、ストレート結線の Cat6 LANケーブル 1本で結線されます。ツイストペアの特性を活かし、信号間クロストークを最小化しています。

| RJ45 Pin | 芯線ペア (T568B) | 信号名 | 電圧レベル | 信号機能 |
|:---:|:---|:---|:---:|:---|
| **1** | 白橙 (ペア2) | **DGND** | 0V | システム共通デジタルグランド |
| **2** | 橙 (ペア2) | **+3V3** | 3.3V | サテライト電源 (XIAO 3.3Vレギュレータより供給) |
| **3** | 白緑 (ペア3) | **ENC_A** | 3.3V/0V | エンコーダ A相パルス (内蔵プルアップ) |
| **4** | 青 (ペア1) | **ENC_B** | 3.3V/0V | エンコーダ B相パルス (内蔵プルアップ) |
| **5** | 白青 (ペア1) | **ENC_SW** | 3.3V/0V | エンコーダ プッシュスイッチ (Mute用) |
| **6** | 緑 (ペア3) | **TOGGLE_SW**| 3.3V/0V | トグルスイッチ状態読取 |
| **7** | 白茶 (ペア4) | **LED_SPK** | 3.3V/0V | スピーカー選択LEDドライブ |
| **8** | 茶 (ペア4) | **LED_HP** | 3.3V/0V | ヘッドホン選択LEDドライブ |

> [!NOTE]
> I2Cバス (SDA / SCL) はメイン基板内で XIAO と PT2258 を接続しており、サテライト基板へは OLED 用として配線されています。長距離引き回しでも安定して動作するよう、メイン基板上に 4.7kΩ のプルアップ抵抗（R1, R2）を実装しています。

## 5. ファームウェア実装方針 (XIAO ESP32-C6)

### 5.1 ピンアサイン定義
- `GPIO0`: PT2258 SDA / OLED SDA
- `GPIO1`: PT2258 SCL / OLED SCL
- `GPIO2`: ENC_A (内部プルアップ、GPIO割り込み)
- `GPIO3`: ENC_B (内部プルアップ、GPIO割り込み)
- `GPIO4`: ENC_SW (内部プルアップ、チャタリング防止)
- `GPIO16`: TOGGLE_SW (内部プルアップ)
- `GPIO17`: LED_SPK (HIGHで点灯)
- `GPIO18`: LED_HP (HIGHで点灯)
- `GPIO19`: RELAY_CTRL (HIGHでリレーON = HP出力、LOWでSPK出力)

### 5.2 制御ロジック
1. **音量制御 (PT2258)**:
   - アドレス: `0x88` (ADDR接地時)
   - エンコーダ回転に応じて 0〜-79 dB（1dBステップ）で減衰量を I2C 送信。
   - Mute 時は PT2258 の Mute コマンド (`0xF9`) を発行し、OLED に「MUTE」を表示。
2. **出力切替 (ポップノイズ防止シーケンス)**:
   - トグルスイッチ操作検知時：
     1. PT2258 をソフトウェア Mute に設定
     2. 20ms ウェイト（音声信号遮断を待機）
     3. リレー（GPIO19）を反転駆動
     4. 30ms ウェイト（リレー接点のバウンス収束を待機）
     5. PT2258 の Mute を解除
   - これにより、スピーカーやヘッドホンから一切の切替ポップノイズが発生しません。
3. **USB 音量同期 & WebUI**:
   - ESP32-C6 の Native USB により、PCと接続時に USB HID Consumer Control（Volume Up/Down/Mute）としても連動可能。
   - ESP-NOW / Wi-Fi を用いて、将来的なホームオートメーション連携も拡張可能。
